# Tools and resources for artists

A personal list from canvast's developer: apps, sites and references that help with creative work. None of them is part of canvast or connected to it, and canvast does not depend on any of them. This page stands on its own and may move to a repository of its own.

## Drawing and painting apps

| Name | Type | Description |
| --- | --- | --- |
| [Krita](https://krita.org/) | Desktop app (Linux, Windows, macOS), free and open source | A full painting program: brushes, layers, animation, colour management |
| [Clip Studio Paint](https://www.clipstudio.net/) | App (Windows, macOS, iPad, Android) | Painting, illustration, comics and animation |
| [Infinite Painter](https://www.infinitestudio.art/) | Mobile app (Android, iOS) | Painting with natural brushes on phones and tablets |
| [ibis Paint](https://ibispaint.com/) | App (Android, iOS, Windows) | Drawing and painting with many brushes, popular for illustration and manga |

## ArtCraft's open-source apps

[ArtCraft](https://getartcraft.com/apps) makes a family of open-source creative apps for macOS, Windows, Linux and (most of them) the web. Most are still early: the stage in brackets is the one their page gives.

| Name | Type | Description |
| --- | --- | --- |
| [PhotoCraft](https://getartcraft.com/apps/photocraft) | Image editor (early alpha) | Edits and paints pictures, made to feel familiar to users of other image editors |
| [VectorCraft](https://getartcraft.com/apps/vectorcraft) | Vector illustration (in development) | Draws and edits vector illustrations |
| [FigCraft](https://getartcraft.com/apps/figcraft) | Interface design (early alpha) | Designs and prototypes interfaces |
| [DesignCraft](https://getartcraft.com/apps/designcraft) | Page layout (in development) | Lays out and publishes pages |
| [EffectCraft](https://getartcraft.com/apps/effectcraft) | Motion graphics (in development) | Motion graphics and visual effects |
| [FilmCraft](https://getartcraft.com/apps/filmcraft) | Video editor (in development) | Edits video |
| [LightCraft](https://getartcraft.com/apps/lightcraft) | Photo library (in development) | Keeps a photo library and develops raw files on your own machine |
| [SoundCraft](https://getartcraft.com/apps/soundcraft) | Audio workstation (in development) | Records, edits and mixes audio |
| [CADCraft](https://getartcraft.com/apps/cadcraft) | CAD (in development) | Computer-aided design and drafting |

Their page also lists office apps (documents, PDFs, slides, spreadsheets).

## Android apps on Linux

| Name | Type | Description |
| --- | --- | --- |
| [Waydroid](https://waydro.id/) | Linux tool, open source | Runs a full Android system in a container on Linux, so Android painting apps can be used without an Android device |

In my own case, I could not find a workaround that makes Clip Studio Paint or Infinite Painter work in Waydroid; other apps may work.

## Image and file utilities

| Name | Type | Description |
| --- | --- | --- |
| [ezgif](https://ezgif.com/) | Website | Make, crop, resize, optimize and convert animated GIFs, WebP and short videos |
| [iLoveIMG](https://www.iloveimg.com/) | Website | Compress, resize, crop and convert pictures in batches |
| [PixelMe](https://pixel-me.tokyo/) | Website | Turns a photo into pixel art (avatars, sprites, bead and stitch patterns) |
| [Haikei](https://haikei.app/) | Website | Generates SVG backgrounds and shapes: waves, blobs, layered steps, gradients |
