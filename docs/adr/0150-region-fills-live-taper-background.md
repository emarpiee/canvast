# ADR 0150 — Fill per region of a network, live Taper, canvas background

- Status: accepted (v0.19.1)

- **Fill per region.** `PathObject.regions = { edges, fills: [half-edge, paint | null][] }`. A region is named by one half-edge round it (2·edge forward, +1 backward; `netCells` in `network.ts`), so no geometry is stored and any move, stretch or turn keeps the name. If the number of edges differs from `edges` (an edge was added or taken away), the own fills no longer apply (they are not guessed at). In Edit nodes a click inside a region of the one picked network picks it (`editor.region`); the fill then changes that region alone (`commitPaint`), a paint equal to the path's takes its own away, and none leaves it empty. Drawing (`regionFills` on the projection), picking, deep zoom colour (`coarse.ts`) and SVG export use `regionSplit`. Release the network drops the fills. Limit: at depths doubles cannot place, the path's own fill is used; the picker shows no live preview on a region (it colours when the picker lets go).
- **Live Taper.** `PathObject.profile` (`taper`, `taper-start`, `taper-end`, `swell`) keeps the line editable: it is drawn as `outlineOf(o, profile)` filled with the outline's paint (`liveOutline`, cached per object); picking, Edit nodes and bounds still use the path and its width (the widest part). The Taper button and the `Width:` commands set it (again: take it away; `Width: even`); Outline stroke bakes it into a shape. SVG export writes the shape as a fill. Limit: deep zoom draws the plain line.
- **Canvas background.** Setting `ui.background` (`#rrggbb`, empty = the app's own) sets `--canvas-bg`; the button beside the pattern one (`paintBucket`) opens the picker; holding it (600 ms, any mouse button or a long touch) goes back to the app's own colour.
