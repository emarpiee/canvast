# ADR 0151 — Grouped Actions-bar menus and reveal by long press

- Status: accepted (v0.19.1)

- **Grouped menus.** The Actions bar has one button for each family of tools instead of a row of icons: Align (with Distribute), Arrange (orders and the space between items), Shapes (the boolean operations and their group), Masks, Sheets (put on a sheet, release it, fit it to its contents; added 2026-10-19) and Path tools (simplify, pen stroke to path, outline stroke, taper, network, divide, shape builder, text to path and on a path). All of them are `openMoreMenu(anchor, items, label, { keepOpen, refresh })` in `ui/more-menu.ts`, the one menu of ADR 0068: each item has an icon, a label and a short hint; the menu is placed beside the button and off the picked things (`placeMenu`); it does not close on a choice or when the pointer leaves, only on Escape or a press outside; `refresh` rebuilds the items after a choice (the ticked operation or gap moves, items that no longer apply go; it closes when none is left). Only what applies to the pick is listed, and a button is hidden when its menu would be empty. A button that opens a menu wears a small corner mark (`aria-haspopup="menu"`), which adds no size. Done and Cancel of the Shape builder stay on the bar while it runs.
- **Reveal on touch.** A finger cannot hover or hold Ctrl, so a long press (450 ms, held still) on Select lists everything under it (`revealHits`, the same shapes Ctrl+hover outlines; hidden and locked things left out) in a keep-open menu. A row outlines its thing while touched or focused (`onActive`, `editor.revealIds`) and a tap picks it (as Ctrl+click: groups entered, masks opened). The first row, "Add to the pick", keeps the menu open so several can be tapped; a press outside ends it. Not done: pen (it hovers: Ctrl+hover works), listing mask members.
