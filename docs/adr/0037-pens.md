# ADR 0037 — Four pens: fine, pencil, ink and marker

- Status: accepted (Phase 5, slice 2; engineering plan §14.39: at least three distinct pens)
- Related: ADR 0001 (exact coordinates), ADR 0020 (groups), brush decisions in `brush-semantics` (thickness lock, follow zoom, stabilizer)

## Decision

A pen turns the points of one gesture into **one or more ordinary strokes** (a polyline with a width and an opacity), so every stroke feature keeps working unchanged: exact coordinates at any depth, hit-testing, the object eraser, deep-zoom colour, storage, archives. The pens differ in how they generate those strokes (`interaction/pens.ts`, pure and unit-tested), not in how strokes are drawn. The chosen pen is a device setting (`pen.kind`) with four buttons on the Pen toolbar.

| Pen | Strokes made | Dynamics and edge |
| --- | --- | --- |
| Fine | one, constant width | the plain pen (unchanged) |
| Pencil | three grouped passes, 90 / 70 / 50 % of the width, 50 / 45 / 40 % opacity | each pass wanders sideways by a smooth deterministic noise (35-55 % of the width, wavelength 6 widths): a darker core with a soft, grainy edge |
| Ink | grouped pieces of similar width | a broad nib at 45 degrees: thick across it, thin along it; pressure where the device reports it (pens, touch), otherwise speed (slow is thicker); widths smoothed and quantized in 20 % steps with hysteresis, so the line is a few pieces, not one per segment |
| Marker | one, 3.2 x the width, 35 % opacity | wide and translucent |

A gesture that makes several strokes is committed as one transaction (one undo step) and **grouped**, so selecting, moving, erasing and the Layers panel treat it as one. The preview while drawing uses the same generator, so what is drawn is what is committed. The thickness lock, "pen size follows zoom", the stabilizer, colour and size work with every pen (follow-zoom pieces are expanded one by one).

## Limits

- The ink pen's variable width is made of pieces with round caps, so a very large change of width between neighbours shows as a step (quantization keeps steps at 20 %); there is no per-point width in the stroke model. Setting the thickness of a selected ink or pencil stroke from the size slider gives all its pieces the same width.
- There is no tilt input and no pen-specific eraser; parameters (nib angle, wander) are constants for now, documented here, not yet settings.
- Pencil grain is geometric (wander and overlap), not a texture image.
